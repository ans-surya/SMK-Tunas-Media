# Aplikasi Sekolah SMK Tunas Media

Demo aplikasi administrasi sekolah berbasis React + Vite.

## Fitur utama
- Dashboard sekolah
- Kelola siswa dan mata pelajaran
- Jadwal mengajar
- Absensi dan penilaian
- Agenda mengajar
- Bimbingan wali
- Cetak kartu QR
- Pusat laporan
- Generator perangkat ajar / AI
- Pengaturan profil sekolah
- Mode demo local-first

## Menjalankan lokal
```bash
npm install
npm run dev
```

Demo menggunakan localStorage secara default (`VITE_DEMO_MODE=true`) sehingga tidak menyentuh database Firebase sumber.
